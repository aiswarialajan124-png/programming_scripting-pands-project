# Iris Dataset Analysis

This project involves analysing the Iris dataset using Python. This project analyses the Iris dataset using Python and Jupyter Notebook. The aim of the project is to explore the dataset, summarise the variables using statistics, and identify patterns and relationships between different species of iris flowers through data visualisation.

## Dataset Description
The Iris dataset was introduced by Ronald Fisher in 1936 and is commonly used for evaluating classification methods.

The dataset contains measurements of 150 iris flowers from three different species:
 - Setosa
 - Versicolor
 - Virginica

Each flower is described using four features:
 - Sepal length (cm)
 - Sepal width (cm)
 - Petal length (cm)
 - Petal width (cm)

These measurements are used to study differences between species and to build classification models.

## Purpose of the Dataset
The Iris dataset is commonly used to test classification algorithms and explore patterns in data. It is used in data analysis and machine learning due to its simplicity and clear structure.

## Analysis Performed
The following analysis was carried out in this project:
- Loading and examining the dataset.
- Checking the dataset structure and confirming there are no missing values.
- Calculation of summary statistics for each variable.
- Saving summary statistics to text file.
- Creation of histograms to visualise distributions.
- Generation of scatter plots to examine relationships between variables.
- Grouped analysis comparing average measurements between species.
- Creation of pairplot to visualise relationships across variables.

## How to Run
1. Open the project folder in VS Code
2. Open the notebook in VS code and run all cells
3. Open 'analysis.ipynb'
4. Run all cells to reproduce analysis

## Project Structure
- 'analysis.ipynb' : Main notebook containing the analysis
- 'data/iris.csv' : Iris dataset used in the project.
- 'outputs/' : Folder containing generated plots and summary statistics.
- 'README.md' : Project documentation.

## Conclusion
The results show that petal length and petal width are the most useful features for distinguishing between species. Data visualisation helped identify clear patterns and relationships within the dataset.
